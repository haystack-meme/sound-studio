# Sound Studio

A desktop web app for designing short UI and game sound effects with the Web Audio API: layered noise/tone sources, sweeping filters, envelopes, randomization, a live waveform and spectrogram, presets, and export to WAV, JSON or a self-contained `playSound()` JavaScript function.

Open: https://haystack-meme.github.io/sound-studio/

Everything runs in the browser; saved sounds live in the browser's local storage.
